开源 NES 测试资料库格式

用于 Android TV 与 Apple TV 的 HTTP 静态资料库约定。每个游戏独立存放，ROM 与封面使用完全相同的文件名主体。

导入地址：
https://dowellhz.github.io/emulator/open-source-roms/

ROM游戏名称.nes
Cover游戏名称.png
SchemaschemaVersion 1

1. 目录结构

open-source-roms/
├── library.json
├── FORMAT.md
├── LICENSE-*.txt
└── Games/
    └── 游戏目录/
        ├── manifest.json
        ├── 游戏名称.nes
        └── 游戏名称.png

文件名区分大小写。推荐使用 505×337 横版 PNG 封面，应用内居中裁切，不拉伸画面。

2. 根索引 library.json

{
  "schemaVersion": 1,
  "title": "Open-source NES Test Library",
  "updatedAt": "2026-09-03T04:51:53Z",
  "games": [
    {
      "id": "falling",
      "manifest": "Games/Falling/manifest.json",
      "updatedAt": "2026-09-03T04:51:53Z"
    }
  ]
}
  • id 必须唯一并保持稳定，只能包含英文字母、数字、点、下划线和连字符，最长 180 个字符。
  • manifest 是相对于资料库根目录的路径。
  • updatedAt 使用 UTC RFC 3339 时间，修改游戏文件或清单后应同步更新。

3. 单游戏 manifest.json

{
  "schemaVersion": 1,
  "id": "falling",
  "title": "Falling",
  "chineseTitle": "Falling",
  "description": "游戏说明",
  "system": "nes",
  "category": "动作",
  "classic": false,
  "mapper": 0,
  "region": "Homebrew",
  "players": 1,
  "rom": {
    "path": "Falling.nes",
    "bytes": 40976,
    "sha256": "64 位小写 SHA-256"
  },
  "artwork": {
    "cover": {
      "path": "Falling.png",
      "bytes": 187727,
      "sha256": "64 位小写 SHA-256"
    }
  }
}
  • 清单中的 id 必须与根索引中的对应 id 完全相同。
  • ROM 和封面路径相对于该游戏的 manifest.json 所在目录。
  • 只能使用安全相对路径，不能以斜杠开头，也不能包含 . 或 .. 路径段。
  • bytes 必须等于实际字节数；sha256 必须是文件内容对应的 64 位小写十六进制值。
  • NES ROM 使用 .nes；封面推荐 .png，也支持 JPG 和 WebP。

4. 限制与校验

  • 单个 ROM 最大 512 MiB。
  • 单张封面最大 32 MiB。
  • 为同时兼容 Android TV 与 Apple TV，单个资料库最多放置 5000 个游戏。
stat -f '%z' 'Falling.nes'
shasum -a 256 'Falling.nes'

5. 简易导入与 HTTP 导入

  • SMB 简易导入可直接扫描裸目录中的同名 .nes 和 .png。
  • GitHub Pages 属于 HTTP 静态服务器，模拟器会读取根目录的 library.json，所以必须保留根索引和每个游戏的 manifest.json。
  • 文件目录网页只供人查看，不参与模拟器导入。

6. 发布要求

只能发布作者明确允许再分发的 ROM 和素材，并保留相应许可证。不得上传商业 ROM、BIOS、私有密钥、密码或 Token。
