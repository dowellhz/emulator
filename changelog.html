RELEASE NOTES

每一次更新。

这里记录公开下载版已列出的更新。不同客户端的系统范围，以各自版本为准。

Android TV 1.5

  • 新增 Nintendo 64、世嘉土星（Sega Saturn）和 Atari 2600 / 5200 / 7800。
  • 街机新增 Kaneko、Tecmo、Mega System 1、SNK 68000、Video System、Psikyo 与 Williams 等机板。
  • 各主机存档都能与资料库服务器同步；上传失败时排队重试，冲突时可以选择保留哪一份。
  • 可以连接 RomM 资料库。
  • 游戏资料新增德语、西班牙语、日语、韩语和繁体中文。
  • ROM 使用与资料库服务器一致的识别规则。
  • 需要 Android 10 或更高版本。

下载 Android TV 版本 →

资料库服务器 1.5.0

  • 新增 PSP（.iso / .cso）和世嘉土星光盘上传。
  • 新增 Kaneko、Tecmo、Mega System 1、SNK 68000、Video System、Psikyo 与 Williams 等街机机板的识别。
  • PlayStation 与世嘉土星的多盘游戏会自动整理到一起。
  • PSP 封面优先按光盘编号查找；网上找不到时，用游戏光盘自带的图片生成封面。
  • 管理页新增德语、西班牙语、日语、韩语和繁体中文。
  • 版本号与客户端一致：服务器 1.5.0 对应各客户端 1.5。

下载服务器 →

macOS 1.4.0

  • 新增 Nintendo 64，支持 .z64 / .v64 / .n64 文件。
  • 各主机 ROM 使用与资料库服务器一致的识别规则。
  • Atari 2600 无法判断制式时，可以选择 NTSC / PAL。
  • 本地导入的 SNES 游戏使用与资料库一致的 IPL，使对应存档互通。
