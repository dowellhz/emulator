06 / BEFORE YOU START

A few things
you might ask.

The complete guide →
Do I need a NAS or a server?+

No. The Mac app can import and manage local ROMs without Docker or a NAS. Add a computer or NAS server when you want several devices to access a shared game library. See the guide for each setup.

Read more ↗
Where do the games come from?+

Import game files you have the right to use. The app includes an original controller tutorial game. Public installers contain no commercial ROMs, BIOS files or private keys.

Read more ↗
What controller do I need on TV?+

Use a Bluetooth or USB game controller compatible with your TV or box. Pair it with the device first, then open a game. The included controller tutorial helps you check the buttons.

Read more ↗
What if a BIOS file is missing?+

Check the named system and file, then provide the matching BIOS from a source you are entitled to use. Ordinary NES cartridges do not need the FDS BIOS. Arcade sets may also need parent sets or shared BIOS files.

Read more ↗
Do all devices support the same games?+

Support depends on the public app version on each device. A new system on one platform does not imply support everywhere. For example, the macOS 1.5.0 download adds Nintendo 64 and Sega Saturn.

Read more ↗
Does my library go to the developer?+

Your ROMs, covers, saves, library addresses and play history are not sent to the developer. When you configure a remote library, the app connects directly to your chosen server.
