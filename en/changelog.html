RELEASE NOTES

What’s new.

Changes documented for the public downloads. System availability depends on the version on each platform.

Library server 1.5.1 for Synology and Docker

  • Play supported games in the browser with fullscreen mode, keyboard and gamepad input, and clickable on-screen controls.
  • The redesigned import section groups ROM uploads, folder selection, and multi-disc setup. Edit and Play appear side by side on game cards.
  • Some games require your own BIOS or arcade parent ROM. Browser play for Nintendo 64 and PSP is currently unavailable.

Download the Synology or Docker package →

Android TV 1.5

  • Adds Nintendo 64, Sega Saturn and Atari 2600 / 5200 / 7800.
  • Adds arcade boards including Kaneko, Tecmo, Mega System 1, SNK 68000, Video System, Psikyo and Williams.
  • Saves for every console sync with the library server; failed uploads are queued and retried, and you choose which copy to keep on a conflict.
  • Can connect to a RomM library.
  • Game information is now also available in German, Spanish, Japanese, Korean and Traditional Chinese.
  • Identifies ROMs using the same rules as the library server.
  • Requires Android 10 or later.

Download for Android TV →

Library server 1.5.0

  • Adds PSP (.iso / .cso) and Sega Saturn disc uploads.
  • Identifies arcade boards including Kaneko, Tecmo, Mega System 1, SNK 68000, Video System, Psikyo and Williams.
  • Multi-disc PlayStation and Sega Saturn games are grouped automatically.
  • PSP covers are looked up by disc serial first; when none is found online, a cover is made from the disc’s own pictures.
  • The management page is now also available in German, Spanish, Japanese, Korean and Traditional Chinese.
  • Version numbers now match the apps: server 1.5.0 goes with the 1.5 apps.

Download the previous Docker 1.5.0 package →

macOS 1.5.0

  • New: Sega Saturn. Import your own game disc images and play.
  • More arcade boards are supported.
  • The interface is now also available in Traditional Chinese, Japanese, Korean, German and Spanish.
  • Nintendo 64 runs much faster; more games now play at full speed.
  • Better controller navigation: the d-pad and left stick behave the same, and each press in a game grid moves exactly one cell.
  • Search matches Traditional and Simplified Chinese and console short names, and starts once you stop typing.
  • A redesigned game launch screen, and "Start Over" in the in-game pause menu.
  • A game renamed in your library no longer causes a sync error.

Download for macOS →

macOS 1.4.0

  • Adds Nintendo 64 support for .z64 / .v64 / .n64 files.
  • Identifies console ROMs using the same rules as the library server.
  • Allows NTSC / PAL selection when an Atari 2600 dump’s TV standard is unknown.
  • Locally imported SNES games use the library’s IPL so corresponding saves match.
